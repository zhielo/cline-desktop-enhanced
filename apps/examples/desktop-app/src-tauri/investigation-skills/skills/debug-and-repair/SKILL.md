# Diagnose and repair

Collect the expected and observed behavior, exact revision, environment, sanitized logs and smallest reproduction. Check project instructions and existing tests. Never request raw credentials or log full provider request bodies containing private attachments.

Trace the input across UI, IPC, runtime and provider/storage boundaries as applicable. Write competing hypotheses and choose the cheapest safe discriminating check. An image preview proves UI retention, not model delivery; compare attachment identities and modality metadata through queueing and the exact provider serializer without exposing media contents.

Add a regression test that fails for the demonstrated defect. Make the smallest coherent correction; retain features and permission checks. Avoid blanket retries, swallowing errors, increasing timeouts or weakening assertions just to pass.

Run the targeted regression, related suites and applicable type/build checks. Record which commands ran, results and untested platforms. If blocked, preserve the patch and report the exact missing prerequisite. Return root cause, files changed, evidence, validation and residual risks. Do not merge or publish solely because compilation succeeded.

Include evidence references and sanitized command/test receipts for checks actually performed. Mark checks not run explicitly.

Never bypass tool approvals, expand filesystem access or treat these instructions as authorization for consequential actions.
