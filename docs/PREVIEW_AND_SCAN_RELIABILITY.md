# Scrollable previews and bounded scans

Artifact text previews use a constrained flex dialog, a shrinkable independently scrollable content region, contained wheel scrolling and keyboard focus. The recorded-code trigger opens a small read-only dialog by pointer/Enter/Space; before/after views use the exact recorded tool data, not the current file. Fragment/diff labels never imply a complete file. Preview text is capped with an explicit notice, rendered as text, and never executed. Selection/copy does not open the dialog. Existing open/reveal and image/PDF/archive boundaries remain.

Whole-tree Smali search is a fixed SDK operation with no Python installation or ad-hoc script required. Up to 32 literal indicators share one read per candidate; missed files avoid line/context allocation. Queries are folded once, traversal skips known dependency/version-control directories and optional explicit basenames, and matching preserves method/line/context metadata. It does not follow symlinks. Directory entries, per-file bytes, total bytes, result count and retained result characters are bounded. Skipped/limited scope is explicit partial coverage, never whole-project absence proof. No target binary executes and no analysis files are modified.

Streamed stages report entries, discovered files, scanned files, bytes read, matches and skips—not estimated percentages or CPU/elapsed-derived progress. Scans yield periodically for cancellation, have a finite deadline and reject identical concurrent scans in the same host/owner without replaying them. This is not cross-host deduplication, a persistent scan cache or automatic resume. Source changes during a scan are not an immutable filesystem snapshot.

Long custom scans/builds should start with `process_session`, explicit argv, an opt-in finite `timeout_ms` and incremental reads. The optional process lifetime survives identity-verified host recovery; deadline expiry requests process-tree termination and records `timedOut`. Completion remains based on observed exit/drain, and failed/unknown identity or signal leaves termination explicitly unconfirmed. No PID-only control, automatic retry or replay is added. Intentionally persistent servers/terminals retain existing behavior when the optional timeout is omitted. Short-command deadlines are not raised. For Python scans use `-u`/flushed counters, enumerate once, read each candidate once, and test all indicators together.

The user's private `find_gates.py` was not provided or present in the repository. This PR does not claim to rewrite/benchmark it or establish a universal speedup. Owned tests establish read-once counters, method results, exclusions, partial budgets, cancellation/deadline, duplicate admission and bounded output. Installed WebView acceptance checks actual long Markdown wheel/keyboard scrolling without a live model turn; React regressions cover recorded code snapshots/tap/keyboard/before-after without filesystem reads.
